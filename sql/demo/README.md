# 可选演示数据（默认不导入）

本目录下的 `02_demo_data.sql` 是一份**人为构造的演示数据集**，仅用于：

- 答辩/演示时快速展示知识库、会话、工单、看板的版式与统计效果；
- 前端 UI 截图与视觉验收；
- 开发期造数。

它**不是真实业务数据**，不代表任何真实用户、订单或服务记录。

## 使用方式

```powershell
# 1. 先初始化表结构与最小账号数据
mysql -uroot -p < sql/01_schema.sql
mysql -uroot -p < sql/02_data.sql

# 2. 需要演示数据时再单独导入（会清空并覆盖业务表）
mysql -uroot -p < sql/demo/02_demo_data.sql
```

## 注意

- 该脚本开头会 `TRUNCATE` 所有业务表，**禁止在生产库执行**；
- 导入后会覆盖 `sql/02_data.sql` 的最小初始化数据（包括账号密码统一为 `123456`）；
- 如不导入，系统默认只有 3 个初始化账号，业务页面保持真实空态。
