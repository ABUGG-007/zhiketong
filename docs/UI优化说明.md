## 3. 页面级改动

### 3.1 全局与布局
- 页面标题 25px / 720 字重，标题 `text-wrap: balance`；正文行高 1.55；
- 卡片圆角 16px、边框 + 轻阴影，统一 hover 提升；
- 顶栏 sticky，主内容区 `tabindex="-1"`；新增「跳到主内容」skip link；
- 侧栏导航项 44px 触控高度，键盘焦点可见；移动端抽屉 + 遮罩 + 关闭按钮；
- 路由切换淡入 + 8px 位移（reduced-motion 下取消）。

### 3.2 登录页
- 表单标签可见，密码可切换显示；账号/密码输入 `aria-label`，错误区 `role="alert"`；
- 服务健康状态 `role="status"`；移除演示账号快捷填充与预填密码，登录表单默认空值；
- 提升 hero 说明文字/时间戳对比度；装饰元素 `aria-hidden`；
- 移动端面板内边距与标题缩放。

### 3.3 数据看板
- 指标卡 6 个，1440 六列 / ≤1360 三列 / ≤640 两列 / ≤360 单列；
- 趋势图：图例、y 轴、`title` 数值、`aria-label` 摘要；移动端标题与图例纵向排列；
- 最近工单/会话：编号单行省略 + 完整 `title`；状态 Pill 带文字；空态/错误重试；
- 表格数字等宽右对齐，行 hover 过渡 150ms。

### 3.4 知识库 / 工单 / 会话 / 坐席 / 用户
- 表格外层 `.table-scroll`：窄屏横向滚动、不撑破卡片；`role="region"` + `aria-label` + `tabindex="0"`；
- 表头 12px/600，数字列右对齐 + tabular-nums，时间统一 `formatDateTime`；
- 每页空态三选一（错误重试 / 清空筛选 / 刷新列表）；
- 知识库新增可聚焦「查看」按钮；会话新增「查看」操作列；
- 坐席负载 `role="progressbar"` + `aria-valuenow`；等待队列显示等待秒数；
- 状态始终「颜色 + 文字」，不单靠颜色传达。

### 3.5 AI 聊天
- 消息区 `role="log" aria-live="polite"`，发送中 `role="status"`；
- 发送按钮空输入禁用、回车发送、发送后焦点回到输入框；
- 新增「最新消息」浮层按钮（滚动离开底部时出现）；
- 移除 emoji 语气符号；气泡/时间/模型标签层级更清晰；
- 侧栏能力说明与转人工入口在窄屏纵向排列。

## 5. 已知限制与后续

1. Element Plus `el-table` 内部为 `div + table` 结构，`aria-label` 只能落在根容器；已用外层 `region` 提供可定位区域，未强行覆盖内部语义。
2. `.table-scroll` 的 `tabindex="0"` 会为每张表增加一个 Tab 停靠点（用于键盘横向滚动）；如认为冗余可移除，不影响鼠标操作。
3. Sessions / Users 表格设置 `min-width`（1110 / 1090），1440 内容区接近满宽，缩窄窗口时出现横向滚动属于预期。
4. 趋势图为 CSS 实现，未提供等价的数据表格；读屏摘要已提供，后续可补 `<table class="sr-only">` 明细。
5. 未做暗色主题（仅深色侧栏）；如需暗色模式，应基于现有 token 增加 `[data-theme="dark"]` 映射并单独验证对比度。
6. 列表数据来自只读过渡接口 `/api/console/*`（直接查 MySQL），M1～M6 正式接口上线后替换；默认初始化后业务表为空，页面展示真实空态。

## 6. UI v3（2026-10-23）

### 6.1 目标与取舍

面向 B 端年轻用户的商业界面：**单一主色、扁平层级、紧凑信息密度、克制动效**。移除渐变、装饰光斑与多色混用，只用主色表达可操作项与选中态，状态色仅用于语义。

| 维度 | v3 规则 |
|------|---------|
| 主色 | `#4f46e5`（hover `#4338ca` / active `#3730a3` / soft `#eef2ff` / line `#dfe3ff`） |
| 中性色 | 背景 `#f7f7f8`、面 `#ffffff`、线 `#e8e8ea`、主文 `#17181c`、次文 `#55585f`、弱文 `#8b8e95` |
| 圆角 | 12 / 10 / 8 / 6，卡片 10～12，控件 8 |
| 动效 | 120 / 180 / 260ms，缓动 `cubic-bezier(.2,0,0,1)`；只用于状态过渡与进场，不做连续装饰动画 |
| 阴影 | 三档轻阴影，仅用于浮层/抽屉/悬浮球，不做卡片悬浮漂移 |
| 导航 | 侧栏 232px，分组标题 11px；顶栏只保留面包屑与账号入口 |

### 6.2 页面级改动

- **登录页**：左侧品牌叙事 + 可交互的悬浮球示例，右侧紧凑登录卡；`-webkit-autofill` 统一压回白底，消除浏览器蓝底；服务状态与初始密码提示放到表单下方。
- **管理端 / 坐席端 / 用户端**：侧栏、顶栏、页面标题与卡片间距统一；指标卡、图表、表格共用同一套边框与文字层级。
- **接入方式页**（`/admin/embed`）：左侧 JS / 独立链接 / API 三种接入配置，右侧浏览器窗框实时预览；主题色、位置、客服名称、欢迎语、未读红点变更后 600ms 防抖重载。试用开关放在页头，避免被悬浮面板遮挡。
- **悬浮球**：`public/embed/zhiketong-widget.js` 零依赖 IIFE，54px 气泡 + 380×600 面板，`≤520px` 自动变为全屏 sheet；按需懒加载 iframe，关闭面板时释放。

## 7. 动效与交互升级 v4（2026-10-25）

依据 ui-motion 动效规范（时长分级、曲线、只动 `transform` / `opacity`、错开节奏、`prefers-reduced-motion` 降级），把 v3 的「克制动效」从零散的 hover 过渡，升级为一套**可维护的动效系统**：统一令牌 → 复用指令与组件 → 逐页落地。本次改动 50 个文件，新增 4 个基础文件。

### 7.1 三条原则

1. 动效只服务三件事：**我从哪里来**（来源）、**我按下去有没有反应**（反馈）、**我等的时候看到什么**（等待）。
2. 不做装饰性连续动画：一页最多一处强调性动效；状态点只在「进行中」呼吸，静止状态不闪。
3. 参数集中：时长、曲线、错开节奏全部收在 `src/styles/motion.css` 的 CSS 变量里，页面内不写魔法数字。

### 7.2 动效令牌

| 类别 | 令牌 | 值 | 用途 |
|------|------|-----|------|
| 时长 | `--zk-dur-instant` | 90ms | 按下反馈 |
| | `--zk-dur-fast` / `base` / `slow` | 140 / 200 / 300ms | 悬停、图标、卡片与气泡 |
| | `--zk-dur-panel` | 380ms | 抽屉与面板 |
| | `--zk-dur-page` | 260ms | 后台路由切换 |
| 曲线 | `--zk-ease-out` / `in` / `in-out` | `cubic-bezier(0,0,.2,1)` / `(.4,0,1,1)` / `(.4,0,.2,1)` | 进场 / 退场 / 双向 |
| | `--zk-ease-soft` | `cubic-bezier(.2,.7,.3,1)` | 骨架与内容浮现 |
| | `--zk-ease-spring` | `cubic-bezier(.34,1.32,.64,1)` | 轻微回弹，超调约 6% |
| | `--zk-ease-emphasis` | `cubic-bezier(.22,1,.36,1)` | 面板滑入、指示器流动 |
| 节奏 | `--zk-stagger` | 45ms | 一组元素依次出场 |
| | `--zk-reveal-y` | 10px | 列表/卡片上浮距离 |

### 7.3 新增基础设施

| 文件 | 职责 |
|------|------|
| `frontend/src/styles/motion.css` | 令牌、关键帧（入场/闪一下/呼吸/扫光/摇头/勾选/旋转）、Vue 过渡（`zk-fade` / `zk-page` / `zk-pop` / `zk-list` / `zk-msg`）、Element Plus 浮层统一过渡、减少动效降级 |
| `frontend/src/composables/motion.js` | `v-reveal` 指令（进视口依次浮现，只播一次）、`useCountUp`（指标数字从 0 滚到实际值）、`useReducedMotion` / `prefersReducedMotion`、`useEnteredOnce`、`haptic` |
| `frontend/src/components/ZkSkeleton.vue` | 7 种骨架（文本/表格/列表/卡片/指标/对话/图表），与真实内容同形同高，一页共用一道 110° 光带 |
| `frontend/src/components/ZkEmpty.vue` | 空状态统一结构：图标—标题—说明—入口依次浮现，替代纯文本「暂无数据」 |

工具类：`.zk-press`（按下 0.97）、`.zk-hover-lift`（桌面抬起）、`.zk-reveal`、`.zk-skeleton`、`.zk-dot-live`、`.zk-flash`、`.zk-table-fade-in`、`.zk-drawer-stagger`、`.zk-shake`。

### 7.4 分模块落地

| 模块 | 关键动效 |
|------|---------|
| 布局导航 | 侧栏选中态改为**流动指示器**（测量 `offsetTop` 后用 `transform` 滑动，300ms，首屏先定位再开过渡）；折叠时品牌/菜单文字 45ms 错开淡出淡入；分组首次入场依次浮现；移动端遮罩 200ms、面板 320ms 且关闭反向一致；等待角标数字翻牌 + 宽度平滑 + 0↔N 出入场；服务状态点仅检测中呼吸 |
| 登录 | 5 个区块 60ms 错开浮现；错误提示预留 34px 常驻空间（布局零位移）+ 400ms 摇头 + 边框变红；密码小眼睛 160ms；提交按钮三段变化（文字淡出 → 转圈 → 对勾描边后跳转，失败摇一下） |
| 在线咨询 | 消息列表改 `TransitionGroup`，历史消息首屏不播、新消息按来源方向进入（用户在右、机器人在左）；发送按钮三态不跳宽；失败气泡变浅红 +「点击重试」原位重发；思考点 1.2s 呼吸；新消息提示条 12px 上滑回弹 + 未读数翻牌；滚动跟随 24px 阈值、`requestAnimationFrame` 每帧追 18%，用户上滑即停 |
| 数据看板 / 统计 | 指标数字 `useCountUp`；柱子 `scaleY` 从底部长出（520ms，错开 68ms，刻度先淡入），首播只播一次；切换区间走 500ms / 25ms 的「旧高度→新高度」形态过渡，不清空重画；首次加载骨架屏后分块 60ms 浮现 |
| 工单 / 知识库 / 质检 | 首屏骨架屏替换空白转圈，数据到达整块淡入；空状态带入口；分类树箭头旋转 + 子项 30ms 错开；时间线节点 40ms 依次出现；抽屉内容错层；对话框提交三段变化；状态变化闪一次（不循环） |
| 后台管理 | 列表页统一「骨架 → 淡入 → 空态」；坐席在线/忙碌点呼吸、离线静止，负载条平滑推进；表单保存三段变化 + 首个错误字段摇头；测试连接转圈不少于 0.8s 再给对勾；租户用量条推进 + 数字滚动 |
| 网页嵌入端 | 悬浮球展开/收起从按钮位置长出（280ms）、未读角标翻牌、清零缩小淡出；嵌入聊天与站内共用同一套应答与入场规则 |

### 7.5 无障碍与性能

- 只动 `transform` / `opacity`；确需尺寸变化处（进度条、折叠面板）沿用既有实现。
- `prefers-reduced-motion: reduce` 时：位移与弹跳全部取消，只保留 ≤120ms 的淡入淡出；骨架光带停止；状态点不闪；JS 动画前统一用 `prefersReducedMotion()` 判断。
- 装饰性动画 `aria-hidden`；`aria-live` 区域不重复播报；错误提示不只靠颜色（动作 + 颜色 + 文字）。
