# 智客通 · UI/UX 优化说明（v2）

> 依据：UI/UX Pro Max 规则体系（无障碍、触控与交互、性能、风格一致性、响应式、字体与色彩、动效、表单反馈、导航、图表）
> 范围：`frontend/` 演示端（登录 / 看板 / 知识库 / 工单 / 会话 / 坐席 / 用户 / AI 聊天）
> 时间：2026-10-20

## 1. 审计发现的问题

| # | 问题 | 影响 | 处理 |
|---|------|------|------|
| 1 | 次级文字 `#8d9bb0` / `#94a3b8` 在浅色背景上对比度不足 4.5:1 | 可读性、WCAG AA | 统一为 `--zk-text-2 #475569` / `--zk-text-3 #64748b` |
| 2 | 缺少统一键盘焦点态，部分自定义可点击元素无焦点环 | 键盘用户无法定位 | 全局 `:focus-visible` 2px 品牌色 + 组件级焦点环 |
| 3 | 移动端侧栏固定 236px，窄屏内容被挤压、无抽屉导航 | 390px 下不可用 | ≤1024px 侧栏改为抽屉 + 遮罩 + 汉堡按钮；≤640px 顶栏精简 |
| 4 | 看板指标卡/趋势图头部在 390px 下换行拥挤 | 移动端可读性 | ≤640px 指标卡 2 列、趋势标题纵向排列、≤360px 单列 |
| 5 | 聊天页发送按钮未随输入禁用、缺少“回到底部”、消息区无读屏播报 | 交互与无障碍 | 禁用态、jump-btn、`role="log" aria-live="polite"`、发送后聚焦输入框 |
| 6 | 表格数字未统一等宽/右对齐，长编号换行 | 数据可读性 | `zk-num` + tabular-nums + 右对齐 + 单行省略 + title |
| 7 | 列表页行点击打开详情仅支持鼠标 | 键盘不可达 | 每行新增可聚焦「查看」链接；`aria-label` 说明目标 |
| 8 | 动效未适配 `prefers-reduced-motion` | 前庭敏感用户不适 | 全局 reduced-motion 降级，动画/过渡几乎关闭 |
| 9 | 图表只有颜色区分、无文本摘要 | 色觉障碍/读屏用户 | 图例 + 数值 title + `role="img"` + aria-label 趋势摘要 |
| 10 | 空态、加载态不统一 | 体验不一致 | 统一骨架/空态结构 + `aria-busy` + 重试按钮 |

## 3. 页面级改动

### 3.1 全局与布局
- 页面标题 25px / 720 字重，标题 `text-wrap: balance`；正文行高 1.55；
- 卡片圆角 16px、边框 + 轻阴影，统一 hover 提升；
- 顶栏 sticky，主内容区 `tabindex="-1"`；新增「跳到主内容」skip link；
- 侧栏导航项 44px 触控高度，键盘焦点可见；移动端抽屉 + 遮罩 + 关闭按钮；
- 路由切换淡入 + 8px 位移（reduced-motion 下取消）。

### 3.2 登录页
- 表单标签可见，密码可切换显示；账号/密码输入 `aria-label`，错误区 `role="alert"`；
- 演示账号卡 ≥48px，可键盘聚焦；服务健康状态 `role="status"`；
- 提升 hero 说明文字/时间戳对比度；装饰元素 `aria-hidden`；
- 移动端面板内边距与标题缩放，≤380px 演示账号单列。

### 3.3 数据看板
- 指标卡 6 个，1440 六列 / ≤1360 三列 / ≤640 两列 / ≤360 单列；
- 趋势图：图例、y 轴、`title` 数值、`aria-label` 摘要；移动端标题与图例纵向排列；
- 最近工单/会话：编号单行省略 + 完整 `title`；状态 Pill 带文字；空态/错误重试；
- 表格数字等宽右对齐，行 hover 过渡 150ms。

### 3.4 知识库 / 工单 / 会话 / 坐席 / 用户
- 表格外层 `.table-scroll`：窄屏横向滚动、不撑破卡片；`role="region"` + `aria-label` + `tabindex="0"`；
- 表头 12px/600，数字列右对齐 + tabular-nums，时间统一 `formatDateTime`；
- 每页空态三选一（错误重试 / 清空筛选 / 刷新列表）；
- 知识库新增可聚焦「查看」按钮；会话新增「查看」操作列；
- 坐席负载 `role="progressbar"` + `aria-valuenow`；等待队列显示等待秒数；
- 状态始终「颜色 + 文字」，不单靠颜色传达。

### 3.5 AI 聊天
- 消息区 `role="log" aria-live="polite"`，发送中 `role="status"`；
- 发送按钮空输入禁用、回车发送、发送后焦点回到输入框；
- 新增「最新消息」浮层按钮（滚动离开底部时出现）；
- 移除 emoji 语气符号；气泡/时间/模型标签层级更清晰；
- 侧栏能力说明与转人工入口在窄屏纵向排列。

## 5. 已知限制与后续

1. Element Plus `el-table` 内部为 `div + table` 结构，`aria-label` 只能落在根容器；已用外层 `region` 提供可定位区域，未强行覆盖内部语义。
2. `.table-scroll` 的 `tabindex="0"` 会为每张表增加一个 Tab 停靠点（用于键盘横向滚动）；如认为冗余可移除，不影响鼠标操作。
3. Sessions / Users 表格设置 `min-width`（1110 / 1090），1440 内容区接近满宽，缩窄窗口时出现横向滚动属于预期。
4. 趋势图为 CSS 实现，未提供等价的数据表格；读屏摘要已提供，后续可补 `<table class="sr-only">` 明细。
5. 未做暗色主题（仅深色侧栏）；如需暗色模式，应基于现有 token 增加 `[data-theme="dark"]` 映射并单独验证对比度。
6. 列表数据仍来自只读演示接口 `/api/demo/*`，M1～M6 正式接口上线后替换。
